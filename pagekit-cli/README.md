# @arovi/pagekit-cli

CLI tooling for [PageKit](https://github.com/arovi-labs/pagekit) — scaffold projects and manage content from the terminal.

## Install

```bash
pnpm add -g @arovi/pagekit-cli
```

## Usage

### Initialize a project

```bash
npx pagekit init
```

Detects your framework, sets up the SDK, and creates your environment config.

### More commands coming soon

- `pagekit init` — scaffold a new project
- `pagekit dev` — start local content server
- `pagekit publish` — publish drafts
