# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in PageKit, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, email security@pagekit.app with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact

We'll respond within 48 hours and work with you to address the issue.

## Scope

This security policy applies to:

- `@pagekit/sdk`
- `@pagekit/mcp`

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
| < latest| No        |
